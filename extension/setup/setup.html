Install the WireRoute helper

The helper is a small program that runs the WireGuard connections. Chrome starts and stops it for you. No admin password needed.

Windows: open PowerShell (Start menu, type PowerShell), paste this and press Enter:
irm https://raw.githubusercontent.com/kinhsman/wireroute/main/install/get.ps1 | iex
Mac: open Terminal, paste this and press Enter:
curl -fsSL https://raw.githubusercontent.com/kinhsman/wireroute/main/install/get.sh | bash

Then come back here and press the button.
